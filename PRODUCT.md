# Product

## Platform

web

## Users

Primary users are recruiters, hiring managers, and collaborators who want to evaluate Ariyan Jahangir's engineering background, work history, technical strengths, and availability for roles or partnerships.

Secondary audiences include peers and technical readers who may review the portfolio for evidence of travel-technology systems, backend/API integration work, and applied machine-learning research.

## Product Purpose

This portfolio exists to present Ariyan Jahangir as a software engineer, communicate key professional evidence, and make it easy for interested parties to review capabilities and initiate contact.

Success means that visitors can quickly understand the person's background, assess fit for technical opportunities, and reach the right contact path with minimal friction.

## Positioning

This is a single-author professional portfolio with a strong engineering and travel-technology emphasis. Its differentiating mechanism is a fast, static, SEO-ready web presence that couples a branded aviation-inspired identity with content managed through JSON data files rather than hand-editing components.

## Operating Context

The site is a static Next.js portfolio meant to be deployed to any simple static host. The public content is maintained by editing JSON under `/data`, while local preview is handled by `npm run dev` and production output is generated by `npm run build` into `/out`.

The repo explicitly records that the domain placeholder `https://ariyanjahangir.dev` should be replaced with the real production domain before launch, and that LinkedIn/GitHub URLs should be verified against real profiles.

## Capabilities and Constraints

- Single-page portfolio experience with sections for experience, skills, education, publications, and contact
- Fully static export for fast hosting and low runtime complexity
- Content-driven updates through JSON files instead of component edits
- Self-hosted fonts and no client-side data fetching for the main content experience
- Resume download is wired to `public/Ariyan_Jahangir_Resume.pdf`
- Public-facing contact information is intentionally limited to what the repository has already approved for publication
- The current implementation includes an aviation-inspired "boarding pass / departure board" identity, but any later redesign must preserve the factual product truth and personal-portfolio purpose
- Open decision: whether to preserve that established visual identity or replace it in a later workstream

## Brand Commitments

- Existing product name: Ariyan Jahangir
- Existing professional voice: practical, technical, concise, and credible
- The portfolio's established identity is a personal website with an aviation-themed presentation language that aligns to the travel-technology work and the site's departure-board motif
- The public site should not publish third-party personal contact details without consent
